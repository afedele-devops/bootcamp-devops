**El Bootcamp de DevOps de Código Facilito es un programa intensivo en línea que cubre desde fundamentos de la cultura DevOps hasta prácticas avanzadas como automatización, infraestructura en la nube, contenedores y CI/CD. Está diseñado para que desarrolladores y administradores de sistemas construyan un portafolio práctico y obtengan un certificado reconocido.**  [Código Facilito](https://codigofacilito.com/bootcamps/devops-g3)  [rodosilva.github.io](https://rodosilva.github.io/myblog/posts/bootcampdevops-avatares/)  

---

## 📚 Temario principal
- **Módulo 1:** Fundamentos de DevOps y Cultura Digital.  
- **Módulo 2:** Linux operativo para entornos DevOps.  
- **Módulo 3:** Control de versiones y colaboración con Git.  
- **Módulo 4:** Automatización.  
- **Módulo 5:** Cloud Computing e Infraestructura como Código.  
- **Módulo 6:** Proyecto final (aplicación práctica).  
- **Módulo 7:** Contenedores y Kubernetes.  
- **Módulo 8:** Integración Continua y Entrega Continua (CI/CD).  
- **Módulo 9:** Monitoreo y resolución de problemas.  [Código Facilito](https://codigofacilito.com/bootcamps/devops-g3)  

---

## 🎯 Proyecto final
- Los estudiantes aplican lo aprendido en un **proyecto real**, integrando backend y frontend en contenedores, desplegando infraestructura como código y configurando pipelines de CI/CD.  
- Este proyecto se convierte en parte del **portafolio profesional**, lo que ayuda a mostrar habilidades prácticas en entrevistas y oportunidades laborales.  [rodosilva.github.io](https://rodosilva.github.io/myblog/posts/bootcampdevops-avatares/)
